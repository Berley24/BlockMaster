# Política de Privacidade - Block Master

**Última atualização:** 2026-01-01  
**Versão:** 1.0  
**Contato:** privacidade@seusite.com

---

## 1. Introdução

O **Block Master** ("nós", "nosso", "o jogo") respeita sua privacidade. Esta política explica quais dados coletamos, como usamos e seus direitos conforme **LGPD (Lei 13.709/2018)** e **GDPR (Regulamento UE 2016/679)**.

Ao jogar, você concorda com esta política.

---

## 2. Dados Coletados

### 2.1 Dados que VOCÊ fornece
- **Nome de exibição** (opcional, para leaderboards)
- **Compras** (processadas pelo Google Play, não armazenamos dados de pagamento)

### 2.2 Dados coletados AUTOMATICAMENTE
| Dado | Finalidade | Base Legal |
|------|------------|------------|
| ID do dispositivo (Android ID) | Identificar instalação única, anti-fraude | Legítimo interesse |
| ID de publicidade (GAID/AAID) | Anúncios personalizados (AdMob) | Consentimento |
| Pontuação, nível, moedas, progresso | Salvar jogo, leaderboards | Execução do contrato |
| Tempo de jogo, sessões | Analytics, balanceamento | Legítimo interesse |
| Modelo dispositivo, OS, região | Compatibilidade, localização | Legítimo interesse |
| IP address (curto prazo) | Segurança, prevenção abuso | Legítimo interesse |

### 2.3 NÃO coletamos
- ✗ Localização precisa (GPS)
- ✗ Contatos, fotos, arquivos pessoais
- ✗ Microfone, câmera
- ✗ Dados bancários (processados pelo Google Play)

---

## 3. Como Usamos os Dados

| Finalidade | Descrição |
|------------|-----------|
| **Funcionamento do jogo** | Salvar progresso, sincronizar entre dispositivos (futuro) |
| **Leaderboards/Conquistas** | Exibir ranking via Google Play Games |
| **Anúncios** | Mostrar anúncios relevantes (AdMob) - opcional |
| **Compras (IAP)** | Validar compras, entregar itens - via Google Play Billing |
| **Melhorias** | Analytics anônimos (nível médio, retenção, crashes) |
| **Segurança** | Detectar trapaças, spam, abuso |
| **Notificações** | Lembretes diários, torneios (opcional) |

---

## 4. Compartilhamento de Dados

| Parceiro | Dados | Finalidade |
|----------|-------|------------|
| **Google Play Services** | ID jogo, conquistas, leaderboards | Funcionalidades sociais |
| **Google AdMob** | GAID, dados de uso | Anúncios personalizados |
| **Google Play Billing** | Token de compra, SKU | Processar pagamentos |
| **Firebase (opcional)** | Analytics, Crashlytics | Monitoramento |

**Não vendemos** seus dados a terceiros.

---

## 5. Seus Direitos (LGPD Art. 18 / GDPR Art. 15-22)

Você pode solicitar a qualquer momento:

| Direito | Como exercer |
|---------|--------------|
| **Acesso** | Ver quais dados temos sobre você |
| **Retificação** | Corrigir dados incorretos |
| **Exclusão** | Apagar todos seus dados ("Direito ao Esquecimento") |
| **Portabilidade** | Receber seus dados em formato legível |
| **Oposição** | Recusar processamento para marketing/ads |
| **Restrição** | Limitar uso temporário |
| **Revogar consentimento** | Para anúncios personalizados, notificações |

**Como solicitar:**  
📧 Email: `privacidade@seusite.com`  
🎮 No jogo: Menu > Configurações > "Apagar Todos os Dados"  
⏱️ Resposta em até **15 dias** (LGPD) / **30 dias** (GDPR)

---

## 6. Retenção de Dados

| Tipo de Dado | Período |
|--------------|---------|
| Progresso do jogo (local) | Até você apagar o app ou solicitar exclusão |
| Progresso na nuvem (futuro) | 2 anos inativo → anonimizado |
| Logs de crash/analytics | 90 dias |
| Dados de compra (Google) | Conforme política do Google |
| ID publicidade (GAID) | Até resetar nas configurações do Android |

---

## 7. Crianças (COPPA / LGPD Art. 14)

- **Não direcionamos** o jogo a menores de 13 anos
- Não coletamos intencionalmente dados de crianças
- Se descobrir que criança <13 nos deu dados, **apagamos imediatamente**
- Pais/responsáveis: contate-nos para remoção

---

## 8. Transferência Internacional

Seus dados podem ser processados em servidores do **Google (EUA, UE, Ásia)**.  
Garantimos proteção via **Cláusulas Contratuais Padrão (SCC)** e **Adequação GDPR**.

---

## 9. Segurança

- Criptografia em trânsito (TLS 1.2+)
- Dados sensíveis **não armazenados** localmente (tokens criptografados)
- Validação server-side de compras
- Rate limiting anti-abuso

---

## 10. Anúncios e Consentimento

### Primeiro lançamento
- Mostramos **dialog de consentimento** (LGPD/GDPR)
- Você escolhe: **Personalizados** / **Não personalizados** / **Sem anúncios (pago)**

### Controle posterior
- Menu > Configurações > "Anúncios Personalizados" (liga/desliga)
- Comprar "Sem Anúncios" remove **todos** os anúncios

### AdMob/Google
- Usam **ID de publicidade (GAID)** - pode ser resetado nas configurações do Android
- Política: https://policies.google.com/technologies/ads

---

## 11. Cookies e Armazenamento Local

- **Não usamos cookies** (não é website)
- Usamos **SharedPreferences / user://** (Godot) para:
  - Save game (progresso, configurações)
  - Cache de anúncios (temporário)
  - Token de notificação push
